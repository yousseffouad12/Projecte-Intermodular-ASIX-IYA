Ansible IaC SSH UFW
AnsibleCore – Automatització de Servidors
Entorn d'Infrastructure as Code basat en Ansible 9.2 que gestiona de forma centralitzada i desatesa dos nodes Ubuntu via SSH amb claus RSA de 4096 bits. El playbook YAML idempotent de ~180 línies orquestra quatre blocs lògics: aprovisionament de grups i usuaris, hardening SSH i firewall UFW, desplegament de Docker i Nginx, i manteniment automatitzat amb cron. Execució verificada amb PLAY RECAP ok=12 failed=0 als dos nodes.
~180 línies de YAML

Proxmox VE TrueNAS RAID 1 NFS
ProxStack – Virtualització Empresarial
Entorn de virtualització complet sobre Proxmox VE 9.1 integrat amb un servidor d'emmagatzematge TrueNAS SCALE amb redundància ZFS en mode Mirror (RAID 1). La infraestructura de xarxa en doble interfície separa el trànsit de gestió del canal NFS privat (10.0.0.0/24). Les VMs aprovisionades utilitzen exclusivament el pool remot Pool_Projecte (47 GiB útils) com a disc principal, garantint protecció de dades fins i tot davant la fallada de l'hypervisor.
~150 línies de config
GitHub

Kubernetes Docker Swarm Nginx MySQL 8
ShopMicro – Orquestració de Microserveis
Plataforma d'e-commerce en microserveis evolució en 4 fases: Docker Compose amb SSL/TLS, Docker Swarm amb 3 nodes, overlay networks i sticky sessions via ip_hash, auditoria de seguretat amb Trivy (CVE-2025-68121) i Docker Secrets, i migració final a Kubernetes amb Minikube, PersistentVolumeClaim, liveness/readiness probes i rolling updates sense downtime. El backend PHP amb BCRYPT i gestió transaccional d'stock completa el sistema.
~320 línies (YAML + PHP)
GitHub

Suricata pfSense IDS/IPS Kali
SentinelFW – Sistema de Detecció d'Intrusions
Implementació d'un IDS/IPS en mode actiu sobre pfSense 2.7.2 amb Suricata 7.0.8 i signatures Emerging Threats Open. El motor realitza Deep Packet Inspection i insereix IPs atacants a la taula de bloqueig pf en temps real (timeout: 3h). Pentesting exhaustiu des de Kali Linux amb Nmap, Hydra, sqlmap i hping3, tant a LAN com a WAN. Notificacions crítiques via bot de Telegram (cURL) i pfBlockerNG per filtrat DNS de dominis maliciosos.
~210 línies (rules + scripts)
GitHub

Zabbix 7.0 SNMP Jira MariaDB
OpsWatch – Monitoratge i Alerting Proactiu
Plataforma de monitoratge centralitzat Zabbix 7.0 LTS sobre Debian 12 que supervisa pfSense i Suricata via SNMP v2c i SSH amb clau RSA. Triggers configurats per CPU, RAM, disc, DNS i DHCP amb gravetat jeràrquica. El flux end-to-end Zabbix → Gmail SMTP → Jira Service Management crea tiquets automàticament i els tanca en resolució, amb informes PDF setmanals automàtics cada dilluns a les 09:00h. Validació completa del cicle en 3 min 42 s documentada.
~190 línies (SQL + Bash)
