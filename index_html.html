// Mòduls del projecte

Cinc blocs. Un sistema.

Cada mòdul és una peça d'un entorn professional complet, des de l'automatització fins al monitoratge actiu.

01
⚙️

Automatització amb Ansible

Entorn centralitzat d'automatització basat en Infrastructure as Code. Gestió de nodes remots sense agents via SSH, playbooks idempotents i quatre blocs d'aprovisionament complets.

Ansible 9.2 Ubuntu Server 24.04 Docker Nginx UFW Fail2Ban
2 nodes gestionats · Playbook complet
02
🖥️

Virtualització amb Proxmox

Entorn de virtualització complet amb Proxmox VE i emmagatzematge redundant TrueNAS SCALE. RAID 1 via ZFS i compartició de recursos a través de NFS per a una protecció real de dades.

Proxmox VE 9.1 TrueNAS SCALE ZFS RAID 1 NFS VirtualBox
50 GiB Mirror · Pool_Projecte online
03
🐳

ShopMicro · Swarm & Kubernetes

Plataforma d'e-commerce en microserveis desplegada en quatre fases: de Docker Compose a Kubernetes, passant per Docker Swarm amb alta disponibilitat i auditoria de seguretat amb Trivy.

Docker Swarm Kubernetes Minikube Nginx MySQL 8.0 PHP Trivy
3 rèpliques · Rolling updates · mTLS
04
🛡️

IDS/IPS Suricata + pfSense

Sistema de detecció i prevenció d'intrusions sobre pfSense. DPI en temps real, regles ET Open personalitzades, pentesting complet amb Kali Linux i notificacions crítiques via Telegram.

Suricata 7.0.8 pfSense 2.7.2 ET Open Rules Kali Linux pfBlockerNG Telegram API
Mode IPS actiu · 7 vectors validats
05
📊

Monitoratge amb Zabbix

Plataforma integral de monitoratge sobre tota la infraestructura. Triggers automàtics, integració Gmail + Jira Service Management, informes setmanals en PDF i validació E2E del flux d'incidents.

Zabbix 7.0 Debian 12 MariaDB SNMP v2c Jira Cloud Gmail SMTP
100% flux incident validat · Informes SLA
// Fases del projecte

De zero a producció

Cada fase construeix sobre l'anterior per crear un entorn professional complet i cohesionat.

Fase 01

Infraestructura base

Configuració de nodes, xarxes internes i automatització amb Ansible. Primer pas cap al model IaC.

Fase 02

Virtualització i emmagatzematge

Proxmox VE amb TrueNAS en RAID 1. Redundància real i provisió de VMs via NFS remot.

Fase 03

Microserveis i orquestració

ShopMicro de Docker Compose fins a Kubernetes. Alta disponibilitat, secrets i auditoria de seguretat.

Fase 04

Seguretat perimetral

IDS/IPS actiu amb Suricata sobre pfSense. Pentesting real i resposta automatitzada a incidents.

Fase 05

Monitoratge i alerting E2E

Zabbix integrat amb Jira i Gmail. Detecció proactiva de fallades i traçabilitat completa d'incidents.
